## Repository structure

Term articles are grouped into folders by their initial letter. Pages use Markdown front matter for metadata and may include LaTeX-style math notation and Mermaid diagrams.

## Contributing

- Add each term as a standalone Markdown file in the folder matching its initial letter.
- Write canonical term content in English, regardless of the language used to request the work.
- Ground factual claims in reliable references, and include sources in the article.
- Follow the repository's [agent instructions](./.github/copilot-instructions.md) for article structure, writing style, and math-rendering compatibility.
- Before submitting, check the Markdown, front matter, formulas, and diagrams for rendering issues.
